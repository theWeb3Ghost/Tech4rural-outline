# Tech4Rural — 12-Week Backend Developer Program

A developer-console style curriculum website built with React + Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy on Render

Create a **Static Site** connected to this GitHub repository.

- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

## Downloads

The weekly download buttons point to files inside:

`public/downloads/`

Placeholder text files are included so the links are visible while developing.
Replace them with real PDFs using the same filenames:

- `week-01.pdf`
- `week-02.pdf`
- ...
- `week-12.pdf`
- `tech4rural-full-curriculum.pdf`

## Routes

- `/`
- `/curriculum`
- `/week/1` through `/week/12`
- `/downloads`
